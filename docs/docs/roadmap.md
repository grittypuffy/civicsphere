# Roadmap

We aim to develop CivicSphere with the objectives framed in [philosophy](/philosophy). Currently, our roadmap is tailored with our philosophy of inclusion and accessibility in mind.

## Enhance Accessibility

- Simplify the onboarding process for end-users by defaults.
- Ensure WCAG 2.1 AAA compliance by migrating to Fluent UI React from TailwindCSS components for certain elements.
- Integrate multimedia accessibility services such as image captioning and image summarization for screen reader users.
- Improve speech-to-text (STT) and text-to-speech (TTS) functionalities to support dialects and voice avatars for customized access.
- Improve accessibility for hard of speech and hearing population using sign language translations.
- Include alternative fonts and theming for people with dyslexia and sensory processing disorders.
- Improve moderation to use semi-automated approach with RBAC for fairness, transparency and accountability to ensure safety of participants.
- Modularization of the platform to support developing countries, expanding outside NYC and USA.
- Develop mobile-native application using Expo for faster development

## Expand Language Support

- Integrate Crowdin for translation and i18n for right-to-left language with screen reader support, expanding to 20 languages over a span of 6 months.
- Verify existing translations with the help of community members by using GitHub for coordination.
- Implement localization (l10n) for interface to support dialects and variants for improved accessibility.

## Update chat agent

- Improve grounding of responses by AI agent by updation of knowledge base and extracting localized data for accuracy when using foreign languages.
- Integrate external services in a modular manner for extraction of context and time sensitive information such as election updates.

## Enaction on issues in decentralized manner

- Introduce real-time polling and community gathering orchestration for community-driven decisions
- Decentralization of platform using ActivityPub for federated access to ensure transparency in operation and orchestration of local political activities.

## Improve Platform Performance

- Optimize existing PWA (Progressive Web App) for better offline functionality and caching using custom service workers.
- Ensure scalability and cost optimization within cloud infrastructure to handle growing traffic efficiently by looking into open-source AI agents and deployment strategies.
- Implement better analytical and database workload for improving performance.
